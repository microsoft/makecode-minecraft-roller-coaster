# add Straight Line

Construct a starting zone for your roller coaster.

```sig
rollerCoasterBuilder.placeTrackStart(pos(0, 0, 0), NORTH)
```

This block constructs a starting zone for your roller coaster, including a small backing wall, a minecart, and a "launch button". All tracks should start with this block.

## Parameters

* **position**: the initial position to start the track.
* **direction**: the initial compass direction track.
