# set lava Protection

Enable or disable the barrier that protects the track from lava.

```sig
rollerCoasterBuilder.setLavaProtection(false)
```

This block enable or disable the barrier that gets constructed when your track goes into lava. If the protection is disabled, lava may destroy your track, but the build will complete faster.

## Parameters

* **value**: a [boolean](/types/boolean) value that when `true` will enable lava protection for the track. If `false` the track isn't protected.
