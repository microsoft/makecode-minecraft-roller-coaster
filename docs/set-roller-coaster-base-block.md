# set Roller Coaster Base Block

Set the block type that will go beneath all of the rails.

```sig
rollerCoasterBuilder.setRollerCoasterBaseBlock(Block.Grass)
```

## Parameters

* **blockType**: the type of block to use for the base of the roller coaster.

```package
makecode-minecraft-roller-coaster=github:microsoft/makecode-minecraft-roller-coaster
```
