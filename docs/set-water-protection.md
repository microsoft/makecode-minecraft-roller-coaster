# set Water Protection

Enable or disable the glass barrier that protects the track from water.

```sig
rollerCoasterBuilder.setWaterProtection(false)
```

This block enable or disable the glass barrier that gets constructed when your track goes into water. If the protection is disabled, water may destroy your track, but the build will complete faster.

## Parameters

* **value**: a [boolean](/types/boolean) value that when `true` will enable water protection for the track. If `false` the track isn't protected.
