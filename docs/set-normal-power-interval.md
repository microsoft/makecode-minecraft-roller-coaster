# set Normal Power Interval

Set how often a powered rail is inserted into the track.

```sig
rollerCoasterBuilder.setNormalPowerInterval(5)
```

This block defines how often a powered rail is inserted into your track. A smaller interval means you will have powered rails more often, making your roller coaster faster.

## Parameters

* **interval**: the time interval, in seconds, for how often a powered rail is inserted into the track.
